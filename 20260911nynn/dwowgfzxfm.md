# 疫情造成法国婴儿荒，谈谈疫情期间备孕需要注意的事

> 更新时间：2026-09-11 (UTC+8)

近年来，我国人口的出生率不断下降，原因是生子养子成本太高，很多人直呼生不起，其实一些其它的国家也面临着同样的问题。近日，疫情造成法国婴儿荒登上了微博热搜，报道称法国2023年婴儿出生总数为二战以来最低，调查显示，这和疫情有着很大的关系。目前临近过年，国内的疫情又有回升的趋势，那么疫情期间备孕有什么注意事项呢？

法国严重的疫情致使很多人推迟了生子计划

## 1疫情造成法国婴儿荒详细报道

法媒报道：法国2023年婴儿出生总数为二战以来最低，2023年，法国的生育率从2019年的每名妇女生育1.86个孩子下降到1.84个，为1945年以来最低水平。

- 专家认为，导致了低生育率的发生有多种原因，包括不确定性和新环境带来的压力、单身人士因封锁更难遇到伴侣、第一次封锁期间不能结婚、疫情下分娩诊所的被迫关闭也加重了“婴儿荒”。

一项调查显示，受疫情影响，欧洲育龄夫妇中有50.7%的人推迟育儿计划，17.3%的人则完全放弃育儿计划。
Tips：
国外严重的疫情下，许多人都放弃了备孕生子的打算，在国内，疫情仍然没有完全平息，对于有备孕打算的家庭来说，有许多要注意的地方。

## 2疫情期间备孕的注意事项

疫情期间，各种现实的问题让孕妈难上加难，怎么吃？怎么动？如何消毒？要不要按时产检？各种问题都让孕妈纠结。总的来说，疫情期间一般不建议备孕，但由于不知道疫情什么时候结束，一味的等待也不是办法，所以对于备孕家庭来说应着重注意以下几点。

全家人都应该做好防护

居家需注意的地方

- 1在疫情期间，最好的防护方法就是居家防护，不走门串巷，尽可能避免亲朋好友的探视；
- 2保持室内空气清新，温度适宜，适当开窗通风；
- 3随时保持手部清洁，饭前便后需要使用洗手液洗手；
- 4提高自身抵抗力，有助于防御外界病原体侵入身体，因此注意个人及家庭成员的营养状况，适当增加运动，进行锻炼，这也有利于备孕。

外出需注意的地方

- 1外出时，必须全程佩戴口罩，日常防护选用医用外科口罩即可；
- 2尽量不去空气不流通、人流量大的地方，如商场；
- 3外出时，随时保持手部清洁卫生，避免使用疑似污染的手触摸脸部，特别是眼睛、鼻子及嘴巴；
- 4忙完尽快回家，避免在外逗留，并立即更换外出衣物、洗手、清洗面部等外露部位，外出的衣物应尽快清洗消毒，外套可悬挂于空气流通处。

以上这些适用于所有的人，无论备孕还是不备孕，由于备孕、怀孕少不了去医院，而医院又是一个比较危险的地方，下面是怀孕后需要着重注意的地方。

孕妈妈需注意的地方

- 1如果需要去医院看诊，请尽量远程联系医生，目前许多医院都有网上问诊渠道；
- 2如必须去医院，遵医嘱做好个人防护到医院接受医疗处理，回家后做好消毒措施；
- 3中晚孕期间需要做的检查会比较多，遵医嘱指导进行。

除了孕妇自己做好个人防护外，家人也是一样的，自己和家人都切不可大意。
Tips：
疫情当下，备孕期间更应该做好防护措施，如果怀孕后不幸中招，那么会对肚子中的胎儿也产生巨大的影响。
