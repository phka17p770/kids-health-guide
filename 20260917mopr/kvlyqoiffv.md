# 常见助孕药物的原理及保存方法

> 更新时间：2026-09-17 (UTC+8)

**1****、克罗米芬**** **

**克罗米芬( CC )是目前在临床应用最为广泛的一种促排卵药物；是与己烯雌酚类似的非甾体激素，在下丘脑、垂体与雌激素竞争占据受体，阻断雌激素的负反馈效应而使 FSH (促卵泡成熟激素)、 LH (促黄体生成素)分泌增加；单独应用于月经第 5 天，联合应用于月经 2～3 天，每天 100mg ，连用 5 天。**

**特点：价格便宜，服用方便，OHSS (卵巢过度刺激综合征)发生率低，但由于有抗雌激素作用可降低子宫内膜的接受性，增加流产率。克罗米芬不作为 IVF (试管婴儿) 中 COH (控制超促排卵)的常规用药。****保存温度:25℃。**

**2****、GnRHa**** ****(****促性腺激素释放激素类似物)**

**GnRHa ****为 GnRH 类似物，是以其他基团取代天然 GnRH 十肽链中第 6、10 位的氨基酸，效能较天然的增加 100 倍，与受体有高度亲和力，应用初期可刺激垂体 Gn 大量释放( flareup )，继续应用可耗竭受体，使 Gn 分泌处于低水平，即降调节作用( down**** ****regulation )****，长期应用可处于闭经状态，用于治疗子宫内膜异位症。停药后经短期的后续作用垂体状态即可恢复。现常规用于 IVF 的 COH**** ****(****控制超促排卵)中，可有效防止出现早发 LH 峰，使卵泡发育同步化，改善卵子质量与内膜环境，从而提高妊娠率。常用剂型有喷鼻与肌注两类，后者效果稳定，又分短效( 0.1mg )与长效( 3.75mg )**** ****两种。达必佳和达菲林是常用的降调节药物，****达必佳 0.1mg /支需要在 2-8℃ 低温保存****。**

**3****、GnRH**** ****antagonist**** ****(****促性腺激素释放激素拮抗剂)**

**GnRH**** ****antagonist ****为 GnRH 拮抗剂，是改变了 GnRH**** ****10 ****肽上所有位点的氨基酸而形成的寡肽，可竞争性地结合 GnRH 受体，阻断内源性 GnRH 对垂体 Gn 细胞的刺激作用，快速抑制 LH 的生成，在 COH 后期短期应用即可达到垂体抑制作用。GnRH**** ****antagonist ****停用一段时间后垂体功能即可恢复，但在 COH 后也需要黄体支持。目前广泛应用于临床的 GnRH**** ****antagonist ****有醋酸西曲瑞克。****保存温度:25℃。**

**4****、HMG**** ****(****人绝经后促性腺激素)**

**HMG ****每支含 FSH 和 LH 各 75 国际单位，常用的有上海丽珠药厂的 HMG 与瑞士 MerckSerono 药厂的 Metrodin ，是 COH**** ****(****控制超促排卵)**** ****中的常用药。可单独使用，但多数情况下与促性腺激素释放激素激动剂( GnRH )及 FSH 联合应用。Gnrha / FSH / HMG / HCG 长方案是目前 COH 的标准方案。****保存温度:25℃**

**5****、FSH**** ****(****促卵泡成熟激素)**

**常用的 FSH(促卵泡成熟激素)有两种，高纯度的 FSH (如 metrodin.hp )，每支含 75 iu**** ****FSH ****与＜0.00liu 的 LH ：基因重组的 FSH (果纳芬gonal- f )，每支含 75 iu**** ****FSH ****。FSH 主要用于卵泡的募集与早期发育，对 HMG 反应不良者早期大剂量应用 FSH 可有改善。虽然 Gnrha / FSH / HCG 可以获得较好的效果，但 Gnrha / FSH / HMG / HCG 方案似乎更符合正常周期的 Gn 分泌，且更经济，两种方案促排结果无统计学差异。果纳芬由于包装不同分为 75 和 450 国际单位，分别称为“小果”和“大果”，“****大果”需要保存在 2-8℃ 低温保存，开启后需要在 28 天内使用完毕。**

**6****、HCG**** ****(****人体绒毛膜促性腺激素)**

**类似 LH ，主要利用其在排卵中的“扳机”作用，模拟 LH 峰，启动卵子的最后成熟与黄体形成，一般使用剂量为 1 次肌注 10000 单位，还可用于黄体支持及改善精液质量。****保存温度:25℃**

**7****、GH**** ****(****生长激素)**

**GH (****生长激素)可促进 IGF-l 的产生，间接加强 Gn 的作用。有国产与进口(商品名为思真)两种。对卵巢反应良好者并不能进一步提高卵巢反应性，对卵巢反应不良者与 Gn 同时应用，可增加获卵数及可移植胚胎数。****保存温度:25℃**
