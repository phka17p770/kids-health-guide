# 三阴性乳腺癌，真的还是杀手吗？

> 更新时间：2026-09-11 (UTC+8)

三阴乳腺癌（TNBC）是指癌组织中雌激素受体（ER）、孕激素受体（PR）和人表皮生长因子受体-2（HER-2）均为阴性的乳腺癌。

靶向治疗:（1）辅助化疗后病灶≥pT2或≥pN1（即≥IIB期）；（2）术前化疗后残留病灶BRCA1/BRCA2胚系突变可考虑将奥拉帕利辅助治疗

免疫治疗

1.免疫治疗方案推荐

肿瘤大类乳腺癌

新辅助治疗PS 0~1 分、PD-L1 CPS ≥

20.早期三阴性乳腺癌，手术前4个周期帕博利珠单抗 + 紫杉醇+卡铂序贯4个周期帕博利珠单抗+多柔比星/表柔比星+ 环磷既胺新辅助治疗，手术后9个周期帕博利珠单抗辅助治疗(I级-1A类)。

检测标志物（新辅助治疗）帕博利珠单抗 +化疗：PD-L1 CPS ≥20

术后辅助治疗PS 0~1 分、PD-L1 CPS ≥

20.早期三阴性乳腺癌，手术前4个周期帕博利珠单抗 + 紫杉醇+卡铂序贯4个周期帕博利珠单抗+多柔比星/表柔比星+ 环磷既胺新辅助治疗，手术后9个周期帕博利珠单抗辅助治疗(I级-1A类)。

检测标志物（辅助治疗）帕博利珠单抗 +化疗：PD-L1 CPS ≥20

一线治疗PS 0-1分，PD-L1(CPS≥10)晚期三阴性乳腺癌:帕博利珠单抗+化疗(II级-1A类)；

PS 0-1分PD-L(IC≥1%)不可手术局部晚期/转移性三阴性乳腺癌:阿替利珠单抗+白蛋白紫杉醇(II级-1A类)。

检测标志物（一线治疗）PD-L1(CPS≥10)

PD-L1(IC≥1%)

2. 检测免疫指标推荐

由于三阴乳腺癌靶药治疗和激素治疗的机会较小，化疗和免疫治疗在该亚型中最常推荐使用，无论时在新辅助治疗，还是辅助治疗、或一线治疗；需检测的指标为PD-L1表达，当PD-L1表达CPS≥10或IC≥1%时，使用帕博利珠单抗+化疗或阿替利珠单抗+化疗会显著获益。
