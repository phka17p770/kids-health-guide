# 科普丨备孕总不成功？可能是甲状腺在 “悄悄捣乱”！

> 更新时间：2026-09-16 (UTC+8)

在不孕门诊里，我们常常听到准妈妈们这样问：“医生，我是来备孕的，为什么还要查甲状腺呀？”

其实很多人不知道，甲状腺虽然只是脖子上一个小小的腺体，却和女性的排卵、月经、受孕能力紧紧绑在一起。不管是甲状腺功能太活跃（甲亢）、不够活跃（甲减），还是出现了甲状腺抗体，都可能悄悄影响怀孕，成为备孕路上看不见的小障碍。

**甲状腺**

**到底是怎么影响生育的？**

甲状腺是我们身体里重要的 “内分泌指挥官”，它分泌的甲状腺激素，参与全身新陈代谢，也直接影响女性的卵巢功能和月经规律。

临床研究发现：不孕女性里，甲状腺功能减退、甲状腺抗体阳性的比例，明显比正常怀孕的女性更高。这也说明，甲状腺和生育能力确实关系密切。

简单区分一下常见的甲状腺问题：

👉 甲亢：TSH 降低，T3、T4 升高

👉 甲减：TSH 升高，T3、T4 降低

👉 亚临床甲亢 / 甲减：只有 TSH 不正常，T3、T4 还在正常范围

👉 自身免疫性甲状腺问题：甲功正常，但甲状腺抗体是阳性

**甲亢**

**会怎样影响备孕？**

甲亢对月经和排卵的影响，会随着轻重程度变化：

**▶ 轻度甲亢**：月经大多还比较正常

**▶中度甲亢**：雌激素、孕激素分泌紊乱，容易出现月经量多、经期频繁、痛经、经前不舒服

**▶中重度甲亢**：会明显打乱排卵，出现月经推迟、量少，甚至闭经，进而导致不孕

如果在青春期前就出现甲亢，还可能影响发育；成年后甲亢则会明显降低受孕概率，也更容易发生流产。

**甲减**

**为什么是备孕 “隐形杀手”？**

甲状腺激素不够时，会间接引起泌乳素升高，进而影响月经和排卵。常见表现就是：月经量异常、月经稀发、闭经，或是反复怀不稳、不孕。

**甲状腺抗体阳性**

**也要重视**

有些姐妹检查发现：甲功完全正常，只有抗体偏高，比如 TPOAb、TGAb 阳性。这类情况属于自身免疫性甲状腺问题。

研究发现：多囊卵巢综合征、子宫内膜异位症患者，常常合并甲状腺抗体异常。所以医生一般会建议：备孕女性、不孕女性，尤其是有 PCOS 或内异症的，最好都筛查一下甲状腺抗体。

**总结**

甲状腺问题常常 “静悄悄”，却实实在在影响备孕。不管是自然怀孕还是做试管，提前查一查甲状腺功能和抗体，及早调整、规范治疗，就能大大提高怀孕概率，也能让孕期更安全、更安心。

希望每一位认真备孕的你，都能避开这些小障碍，早日迎来属于自己的好消息～
